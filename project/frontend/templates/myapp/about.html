About Ai-WildEye

Ai-WildEye is an intelligent wild-animal detection system built using a MobileNetV2-based deep learning model. It classifies various species from images and triggers alerts for selected animals.

The project supports training custom datasets and provides a web interface for administrators and staff to manage alerts and view detection history. It is designed to assist in wildlife monitoring and conservation efforts.
