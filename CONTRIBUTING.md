# Contributing

Thank you for your interest in contributing to this project.

## Getting Started

1. Fork the repository.
2. Create a feature branch from `main`.
3. Make your changes and keep them focused.
4. Test your changes locally using the project's documented setup.
5. Commit with a clear, descriptive message.
6. Open a pull request against `main` and explain what changed.

## Code and ML Contributions

- Follow the existing Python, Django, and machine-learning project conventions.
- Keep code, model, and data-related changes clearly documented.
- Avoid committing large generated files or datasets unless they are intentionally part of the repository.
- Do not commit secrets, credentials, API keys, `.env` files, or sensitive data.
- Update documentation when setup, model behavior, dependencies, or APIs change.

## Pull Requests

Please describe the purpose of the change, how it was verified, and any effects on data, models, configuration, or application behavior.

## Issues

Before opening an issue, check whether a similar issue already exists. For bugs, include reproduction steps, relevant error messages, and environment details.
